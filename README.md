# 随选剪贴板

Windows 本地剪贴板工具。选中文字自动复制，悬浮历史面板支持搜索、置顶和双击粘贴。

此版本不包含账号、注册、云同步、服务器接口或联网更新功能。程序没有上传剪贴板数据的代码。历史与应用设置仅在本机保存。

## 下载

在本仓库 Releases 页面下载 `SelectionClipboard-0.4.5.exe`，直接运行。支持 Windows 10/11，依赖系统 .NET Framework。

## 使用

- 鼠标拖选文字或双击选词后自动复制。
- 按住 Alt 临时跳过；Ctrl+Alt+C 暂停或恢复。
- “生效应用”可设置仅在指定软件中工作。
- 单击悬浮“复制历史”展开或收起，拖动调整位置，下次启动自动恢复；右键悬浮按钮或通过托盘菜单调整透明度（0%–80%），重启后保留。
- 先点击目标输入框，再双击历史条目粘贴。面板保持展开，粘贴不会把条目重新移到顶部。
- 通过系统托盘菜单退出；首次打开显示使用说明。

## 本地数据

最近 100 条普通历史和置顶内容保存在 `%LOCALAPPDATA%\SelectionClipboardPublic`。历史采用 Windows 当前用户 DPAPI 加密，保存时保留备份，主文件损坏时尝试恢复。应用设置单独保存在本机。DPAPI 数据依赖当前 Windows 用户，不支持直接复制到其他系统解密。

## 构建和检查

在 Windows PowerShell 执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\构建.ps1
```

无需 Node.js、WebView2 或第三方运行库。构建脚本执行内置历史、应用匹配及内部剪贴板通知处理自检。`tests/HistoryStoreTest.cs` 检查跨进程持久化、备份恢复和损坏保护。

## 限制

自动复制使用鼠标动作判断，可能误触，也不保证所有应用、管理员窗口或受保护内容可用。建议按需要限制生效应用。选中文字准备覆盖输入时可按住 Alt，防止覆盖待粘贴内容。自动粘贴依赖窗口焦点，失败时仍可手动粘贴。
